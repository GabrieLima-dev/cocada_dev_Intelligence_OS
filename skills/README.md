# Skills

Skills são pacotes opcionais de capacidade recorrente para um runtime específico. A inteligência canônica permanece em Brand OS, contratos, workflows e memória; uma skill referencia esses arquivos em vez de copiá-los.

Para adicionar uma skill:

1. Escolha uma tarefa estreita e repetida, não um agente inteiro por padrão.
2. Declare trigger, entradas, saídas, leituras, escritas e limites.
3. Não embuta segredo, integração falsa ou estado estratégico.
4. Inclua evals e versão; proponha via evolution se mudar comportamento central.
5. Mantenha instruções portáveis ou isole adaptações de fornecedor.

Nenhuma skill executável é necessária na V1; o Orchestrator e os workflows já formam a interface mínima.
