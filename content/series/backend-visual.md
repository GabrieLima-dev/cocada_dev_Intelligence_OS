# Backend Visual

**Objetivo:** compreensão e salvamento. **Público:** estudantes e devs que precisam visualizar fluxo. **Estrutura:** pergunta → diagrama progressivo → falha/trade-off → mapa final. **Hook típico:** curiosity gap/comparison. **Duração:** 30–75s ou carrossel. **Formato:** diagrama como elemento principal + voz/rosto. **CTA:** salvar o mapa. **Mecanismos:** utility, transformation. **Exemplos:** request entre serviços, Kafka, cache. **Métricas esperadas:** UNKNOWN; observar saves, conclusão e replay.
