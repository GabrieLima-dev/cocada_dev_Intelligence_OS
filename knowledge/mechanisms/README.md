# Biblioteca de mecanismos

Mecanismos descrevem por que alguém presta atenção ou age; não são fórmulas garantidas. Cada conteúdo declara um mecanismo principal e, no máximo, dois secundários. Resultados reais devem ser ligados por content ID, nunca incorporados ao arquivo como verdade sem curadoria.

| Mecanismo | Intenção dominante |
|---|---|
| curiosity | descobrir informação incompleta |
| identification | reconhecer a própria experiência |
| utility | guardar/aplicar depois |
| shareability | enviar para alguém específico |
| authority | confiar na explicação/demonstração |
| status | expressar competência ou identidade |
| surprise | atualizar um modelo mental |
| controversy | avaliar uma discordância real |
| conflict | acompanhar problema e consequência |
| humor | aliviar e reconhecer cultura dev |
| transformation | visualizar antes/depois |
| fear-of-missing | agir diante de prazo/risco real |
