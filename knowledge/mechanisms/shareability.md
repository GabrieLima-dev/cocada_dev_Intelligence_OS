# Shareability

**Definição:** valor social claro em enviar o conteúdo para uma pessoa específica. **Quando usar:** linguagem comum para um problema, alerta relevante ou identificação de equipe. **Quando não usar:** choque artificial ou pedido explícito sem motivo. **Sinais:** “vou mandar para o time”, utilidade relacional, inside joke acessível. **Exemplo:** “Manda para quem chama toda chamada HTTP de API.” **Riscos:** polarização barata. **Métricas relacionadas:** shares/reach, destinatários mencionados e follows qualificados.
