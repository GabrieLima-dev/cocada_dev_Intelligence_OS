# Contrarian

**Template:** “Eu parei de [prática aceita] desse jeito.” **Quando funciona:** há experiência/evidência e alternativa útil. **Primeiro frame:** contraste antigo/novo. **Exemplo:** “Eu parei de estudar Java como uma lista de APIs.” **Payoff:** contexto e método melhor, sem universalizar. **Resultados observados:** UNKNOWN.
