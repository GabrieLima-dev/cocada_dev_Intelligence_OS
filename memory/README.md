# Memória compartilhada

A memória separa evento bruto, interpretação e conhecimento curado.

| Área | Conteúdo | Política |
|---|---|---|
| `creator/`, `audience/` | fatos e hipóteses sobre pessoas | fonte e confiança |
| `content/` | índice e relações de conteúdos | ID imutável |
| `performance/` | resumos derivados | eventos brutos ficam em analytics |
| `experiments/` | conclusões de testes | ligar ao EXP e conteúdos |
| `patterns/` | padrões candidatos/validados | evidência comparável |
| `decisions/` | por que uma escolha foi feita | não apagar resultado ruim |
| `learnings/` | claims curados | confiança + amostra + revisão |
| `brand/` | ponte para Brand OS | sem duplicar identidade |

Estágios epistêmicos: `OBSERVATION → HYPOTHESIS → STRONG_HYPOTHESIS → PATTERN → VALIDATED_PRINCIPLE`. Confiança ortogonal: `LOW`, `MEDIUM`, `HIGH`, `VALIDATED`.
