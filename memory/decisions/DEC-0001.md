# Decisão

## Consequências e trade-offs

A V1 funciona com Markdown, YAML, JSON Schema e Python padrão. Ela não agenda scans, publica nem importa analytics automaticamente. Integrações futuras devem preservar IDs, proveniência e aprovação humana.

## Revisão futura

Reavaliar persistência ou automação quando volume, colaboração ou falhas operacionais fornecerem evidência concreta; não migrar por antecipação.
